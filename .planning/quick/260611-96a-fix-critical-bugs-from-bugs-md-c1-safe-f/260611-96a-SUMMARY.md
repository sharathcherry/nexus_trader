# Quick Task 260611-96a: Fix Critical Bugs C1-C7 from BUGS.md Summary

**One-liner:** Repaired the seven session-killing bugs — broken _safe_fetch callers, stale-auth NameError, false-circuit cache TTL, unmanaged circuit positions, never-resetting daily state, restart deadlock, and fake shutdown liquidation — so the intraday loop can complete a real managed trading session.

## What Was Done

### Task 1 — Data-path fixes (C1/C2/C3) — commit 08c1c91
- **C1:** Three stale `_safe_fetch` call sites updated to the current signature: `agents/agent_i4.py:78` (`is_intraday=True`), `agents/agent_i4.py` Nifty filter and `execution/scheduler.py` morning briefing (`is_intraday=False, period_days=2`). Dead `period`/`interval` kwargs removed.
- **C3:** `data/market_data.py` gains `_cache_ttl_intraday = 45` (below the 60s poll). `_safe_fetch` selects TTL by `is_intraday`; `_safe_fetch_yf` accepts a `ttl` parameter (default 300s, not in cache key, not forwarded to yfinance) and the intraday yfinance fallback passes `ttl=45`. Daily and `get_global_indices` paths keep 300s.
- **C2:** `execution/scheduler.py` imports `os`, `subprocess`, `sys` at module top; spawns `[sys.executable, upstox_script]`; sends `notifier.send_error("Upstox Token Refresh Failed", ...)` on non-zero exit (stderr truncated to last 500 chars) and on exceptions. Method still never raises.

### Task 2 — Position-safety fixes (C4/C5/C6/C7) — commit ae4c83c
- **C4:** `agents/agent_i6.py monitor_positions` reordered: price resolve → SL hard exit → target hard exit → circuit recovery (`circuit_set.discard` when price differs from previous cycle's deque tail) → circuit detection → `continue` skips only partial-exit/trailing-SL. Module docstring updated. `_check_circuit` unchanged.
- **C5:** `execution/portfolio.py` extracts the daily reset into public `reset_daily_state_if_new_day()`, called from `_restore_state`, first statement of `buy()` and `sell()`, and in `force_squareoff_all()` BEFORE the `force_squaredoff == "1"` idempotency check. `run_pre_market_pipeline` calls it right after the `is_trading_day` guard so the watchlist DELETE happens at 08:30, not at the first day-2 buy.
- **C6:** `run_market_session` sets `_watchlist_ready` after the DB watchlist restore when unset (the job only fires 09:15-15:15, so unset always means a restart).
- **C7:** `main.py` shutdown no longer calls `force_squareoff_all({})`. It logs open positions (count + symbols) and leaves them in DB for restart reconciliation or the 15:15 squareoff. No `force_squaredoff` mutation.
