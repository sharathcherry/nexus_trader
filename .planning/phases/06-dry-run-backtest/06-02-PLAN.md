  run(self) -> dict: Initialize all_trades=[], equity_curve=[self.capital], running_capital=self.capital, trading_days_processed=0. Iterate current_date from self.start_date to self.end_date (inclusive) with timedelta(days=1) steps. For each date: if config.is_trading_day(current_date) call _simulate_day(current_date, running_capital, equity_curve), extend all_trades, increment trading_days_processed, log INFO with date + trade count + equity. Return self._compute_metrics(all_trades, equity_curve, trading_days_processed).

  _compute_metrics(self, trades: list[dict], equity_curve: list[float], trading_days_processed: int) -> dict: Compute all 8 metrics:
  - total_trades = len(trades)
  - win_rate = len([t for t in trades if t['net_pnl'] > 0]) / total_trades (0.0 if no trades)
  - total_net_pnl = sum(t['net_pnl'] for t in trades)
  - total_return_pct = total_net_pnl / self.capital (0.0 if capital==0)
  - sharpe_ratio: daily_returns = [(equity_curve[i+1] - equity_curve[i]) / self.capital for i in range(len(equity_curve)-1)]. mean_r = mean of daily_returns. std_r = population std (sum of squared deviations / N, then sqrt). sharpe = (mean_r / std_r) * math.sqrt(252) if std_r > 0 else 0.0. Return 0.0 if no daily_returns.
  - max_drawdown_pct: iterate equity_curve tracking peak; dd = (peak - val) / peak; track max dd. Return as decimal (e.g. 0.15 for 15%).
  - profit_factor = sum of positive net_pnl / abs(sum of negative net_pnl); float('inf') if no losses; 0.0 if no wins.
  - monthly_returns: group trades by t['date'][:7] ('YYYY-MM'), accumulate pnl and count; return sorted list of {'month': str, 'pnl': float, 'trades': int}.
  - Return dict with all 8 keys plus 'trading_days_processed' as a 9th bonus key (used by _save_results in backtest.py but NOT printed in terminal report).
  </action>
