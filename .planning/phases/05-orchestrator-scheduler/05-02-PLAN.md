## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI → main.py | --dry-run is a boolean store_true flag; no free-text input; no injection risk |
| APScheduler thread → NexusTrader | Background thread calls NexusTrader methods; exceptions must not escape (scheduler thread death) |
| NexusTrader → agents | Each agent call is isolated in try/except; one agent crash does not block the pipeline |
| main.py → config | API key values are never printed; only presence/absence is shown in banner |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02 | Denial of Service | NexusTrader public methods | mitigate | All three methods wrapped in top-level try/except Exception — log and return; BackgroundScheduler thread stays alive after any crash |
| T-05-03 | Information Disclosure | print_banner() API key display | mitigate | Only presence/absence shown (config.GEMINI_API_KEY truthy check); key value never printed; verified in D-09 and PATTERNS.md |
| T-05-04 | Integrity | force_squareoff_all on Ctrl+C | mitigate | PaperPortfolio.force_squareoff_all() must be idempotent; called in shutdown path before save_state; order is D-06 step 1 before step 2 |
| T-05-05 | Denial of Service | scheduler.shutdown() hanging on Windows | mitigate | Always wait=False in TradingScheduler.shutdown(); prevents deadlock when market_session job is mid-execution on Windows (no SIGTERM) |
| T-05-06 | Tampering | NSE_HOLIDAYS_2026 hardcoded set | accept | Static data; no network dependency; worst case is one missed/extra paper trading day; reviewed annually |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed — all dependencies already pinned in requirements.txt and installed in project venv |
