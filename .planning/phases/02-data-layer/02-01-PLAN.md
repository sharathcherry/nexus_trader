    Private helper `_safe_fetch(self, symbol: str, **kwargs) -> pd.DataFrame`:
    - Calls `time.sleep(_RATE_LIMIT_DELAY)` BEFORE the yfinance call (per D-01 and DATA-09)
    - Calls `yf.Ticker(symbol).history(**kwargs)` inside try/except Exception
    - If df is None or df.empty: logs `logger.warning(f"_safe_fetch({symbol}): empty response — possible 429 or delisted")` and returns pd.DataFrame()
    - On exception: logs `logger.error(f"_safe_fetch({symbol}): {e}")` and returns pd.DataFrame()
    - Always passes prepost=False in kwargs default — callers override if needed

    Public method `get_previous_close(self, symbol: str) -> float | None`:
    - Calls self._safe_fetch(symbol, period="5d", interval="1d", prepost=False, auto_adjust=True)
    - If df.empty or len(df) < 2: log warning, return None
    - Return float(df["Close"].iloc[-2])
    - Wrap in try/except, return None on any exception

    Public method `get_premarket_price(self, symbol: str) -> float | None`:
    - Calls self._safe_fetch(symbol, period="2d", interval="1d", prepost=False, auto_adjust=True)
    - If df.empty: return None
    - Return float(df["Close"].iloc[-1])
    - Wrap in try/except, return None on any exception

    Public method `get_intraday_candles(self, symbol: str) -> pd.DataFrame`:
    - Calls self._safe_fetch(symbol, period="1d", interval="5m", prepost=False, auto_adjust=True)
    - If df.empty: return pd.DataFrame()
    - Session filter (per RESEARCH.md §2): if df.index.tz is None: df.index = df.index.tz_localize("UTC"); df.index = df.index.tz_convert(IST); session_start = df.index[0].replace(hour=9, minute=15, second=0, microsecond=0); df = df[df.index >= session_start]
    - Return df[["Open", "High", "Low", "Close", "Volume"]].copy()
    - Wrap in try/except, return pd.DataFrame() on any exception

    Public method `get_historical_data(self, symbol: str, period: str = "60d") -> pd.DataFrame`:
    - Calls self._safe_fetch(symbol, period=period, interval="1d", prepost=False, auto_adjust=True)
    - If df.empty: return pd.DataFrame()
    - Return df[["Open", "High", "Low", "Close", "Volume"]].copy()
    - Wrap in try/except, return pd.DataFrame() on any exception

    Public method `get_atr(self, symbol: str, period: int = 14) -> float | None`:
    - Calls self.get_historical_data(symbol, period="30d")
    - If df.empty or len(df) < period + 1: return None
    - Compute ATR inline using pandas (no ta library): high=df["High"], low=df["Low"], close=df["Close"]; tr = pd.concat([high-low, (high-close.shift()).abs(), (low-close.shift()).abs()], axis=1).max(axis=1); atr_val = tr.rolling(period).mean().iloc[-1]
    - Return float(atr_val) if not pd.isna(atr_val) else None
    - Wrap in try/except, return None on any exception

    Public method `get_global_indices(self) -> dict[str, float]`:
    - Iterate over _GLOBAL_INDICES items
    - For each (name, symbol): call self._safe_fetch(symbol, period="2d", interval="1d", prepost=False, auto_adjust=True) inside try/except
    - If df not empty: add result[name] = float(df["Close"].iloc[-1])
    - On exception for individual symbol: log warning and continue (partial result acceptable — per RESEARCH.md §4)
    - Return result dict (empty {} if all fail, partial dict if some fail)
    - The outer method does NOT have a try/except — only inner per-symbol try/except

    Do NOT import ta anywhere. All ATR math is inline pandas.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| yfinance → market_data.py | External network data enters via yfinance; all responses are untrusted (empty, malformed, or rate-limited) |
| market_data.py → callers | All public methods return safe typed values; no exceptions propagate |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Tampering | yfinance response data | mitigate | Validate df not None and not empty after every call; check column existence before iloc access; return failure values instead of processing bad data |
| T-02-01-02 | Denial of Service | yfinance rate limiting (429) | mitigate | 0.2s time.sleep() between every sequential Ticker call in _safe_fetch; 429 returns empty DataFrame (no exception), covered by df.empty guard |
| T-02-01-03 | Information Disclosure | API keys in data/market_data.py | accept | market_data.py does not use API keys; no .env access; yfinance requires no authentication for NSE data |
| T-02-01-04 | Spoofing | NSE symbol injection | accept | All symbols come from hardcoded universe list (data/universe.py) or agent-controlled inputs; no user-facing symbol input at this layer |
| T-02-01-05 | Information Disclosure | 15-minute data delay | mitigate | Module-level logger.info() fires on import warning all consumers that data is 15 minutes stale; embedded in all trade records per D-15 decision in STATE.md |
| T-02-01-SC | Tampering | No new package installs in this plan | accept | No npm/pip/cargo installs — only file creation using existing pinned dependencies |
</threat_model>
