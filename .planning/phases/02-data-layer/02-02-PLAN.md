    Add the remaining 4 @staticmethod methods to the Indicators class in data/indicators.py. Read the file first to see current state before editing.

    Method rsi(df: pd.DataFrame, period: int = 14) -> pd.Series:
    - delta = df["Close"].diff()
    - gain = delta.clip(lower=0).rolling(period).mean()
    - loss = (-delta.clip(upper=0)).rolling(period).mean()
    - rs = gain / loss.replace(0, float("nan"))  — prevent division by zero
    - Return 100 - (100 / (1 + rs))
    - Initial rows will have NaN (normal for rolling window); callers use .dropna() before bounding checks

    Method atr(df: pd.DataFrame, period: int = 14) -> float:
    - high, low, close = df["High"], df["Low"], df["Close"]
    - tr = pd.concat([high - low, (high - close.shift()).abs(), (low - close.shift()).abs()], axis=1).max(axis=1)
    - val = tr.rolling(period).mean().iloc[-1]
    - Return float(val) if not pd.isna(val) else 0.0
    - Returns 0.0 (not NaN, not raises) when DataFrame is too short to compute ATR

    Method orb(df: pd.DataFrame, n_minutes: int = None) -> tuple[float, float]:
    - Docstring: "Opening range high/low for first n_minutes of session. Assumes 5-min candles. Default resolves from config.ORB_MINUTES (15) → first 3 rows."
    - if n_minutes is None: from config import config; n_minutes = config.ORB_MINUTES
    - n_candles = max(1, n_minutes // 5)
    - opening = df.head(n_candles)
    - If opening.empty: return (0.0, 0.0)
    - Return (float(opening["High"].max()), float(opening["Low"].min()))
    - Note: n_minutes=None sentinel triggers late import of config.ORB_MINUTES (per D-06 and PATTERNS.md idiom). Caller may still pass an explicit int to override.

    Method volume_ratio(df: pd.DataFrame, lookback: int = 20) -> float:
    - If len(df) < 2: return 0.0
    - current_vol = df["Volume"].iloc[-1]
    - avg_vol = df["Volume"].iloc[:-1].tail(lookback).mean()
    - If avg_vol == 0 or pd.isna(avg_vol): return 0.0
    - Return float(current_vol / avg_vol)
